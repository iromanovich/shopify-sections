# shopify-sections

This repository started in April 2026 as a place for reusable Shopify sections. The real sections ended up where they belong: in production storefronts.

Code excerpts from one of them, a subscription buy box on native Selling Plans with the analytics and performance layer around it, are published here: [shopify-subscription-storefront](https://github.com/iromanovich/shopify-subscription-storefront).

The rules I build sections by are in [claude-code-setup](https://github.com/iromanovich/claude-code-setup). Archived to keep the history; nothing else will land here.
